\section{The question, and what was fixed before the numbers existed}

A multimodal language model carries textbook knowledge about what pathology looks like. This study
asks what that knowledge is worth, measured in the currency a practitioner cares about: labelled
images. On \numDatasets\ MedMNIST 2D benchmarks spanning \numDatasets\ modalities, a
vision--language model scores each image against a cited bank of diagnostic visual features, and
four arms are compared on one shared test sample:

\begin{itemize}
  \item \textbf{A, zero-shot} --- the model's class distribution from the image and the class names.
        No labels.
  \item \textbf{B, textbook-only} --- nearest class fingerprint from the concept bank. No labels.
  \item \textbf{C, concept probe} --- regularised logistic regression on the concept scores, $n$ labels.
  \item \textbf{P, pixel probe} --- the same regression on frozen ImageNet features, the same $n$ labels.
\end{itemize}

Arms C and P differ in their features and in nothing else: the same classifier, the same
regularisation search and the same labelled subsets. The four hypotheses and their decision rules
were fixed in \texttt{WORKFLOW.md} before any number existed, and are reported here as they were
written.

One further comparison point was added after those results were in hand, and it decides nothing.
The \textbf{published literature} for these same six tasks is read in as a fixed ceiling, so the
arms can be placed against a benchmark trained on the full training split
(Section~\ref{sec:literature}). It is an extension in the sense of \texttt{WORKFLOW.md}
section~10: no \emph{supported} verdict in this report reads it.

\section{Data and provenance}

Six MedMNIST v2 224-pixel benchmarks (Zenodo record 10519652), read from the pinned release files
whose names, checksums, split sizes and label maps are recorded in \texttt{config/medmnist.yaml}
and held to the installed \texttt{medmnist} package by the smoke tier. Per dataset: a 500-image
test sample shared by every arm and every model, and a 2000-image labelled pool from the official
train split, both drawn with seed~0.

The concept bank (\texttt{data/concepts/}) was built outside the workflow by literature review,
with every feature and every class fingerprint carrying a citation. \textbf{Expert review is
simulated}: no clinician has reviewed those files, and each says so. Nothing downstream should be
read as if one had.

\textbf{A stated limit.} The test sample is random rather than stratified, so a rare class is thin:
dermamnist holds six dermatofibromas and five vascular lesions of its 500. Because the AUC is the
unweighted mean of one-vs-rest columns, such a column counts as much as one built on hundreds, and
the absolute per-dataset AUCs should be read with that in mind. The hypotheses are paired
differences on the same images, where a thin column is common mode.

\section{Methods as executed}

Every response from the model was archived raw, with the served model name and the hash of the
prompt string that produced it; everything downstream is a deterministic function of that archive.
An answer that did not parse, or that named a level outside its concept's own scale, was recorded
as missing and never repaired into a value. Concept levels map to equally spaced values on $[0,1]$;
a missing answer takes the labelled pool's median for that concept and is flagged by an indicator
column. Arm~B scores a class by the negative mean absolute difference over the concepts that both
the fingerprint and the image commit to. Arms C and P choose their L2 strength by cross-validation
inside the $n$ labelled images, with no validation set. The metric is
\texttt{medmnist.evaluator.getAUC}, and every interval is a 95\% percentile interval from a paired
bootstrap over the test images, shared by every arm.

\section{Results}

\subsection*{H1 --- Substitution: \hOneSupported}

\emph{Textbook features are worth a measurable number of labelled images.} Supported if the median
$n_B$ is at least 100 \textbf{and} arm C beats arm P at the smallest labelled subset on every
dataset. Arm C won on \cBeatsPWins\ of \numDatasets\ datasets (one-sided sign test
$p = \cBeatsPp$); the pixel probe never reached the textbook arm inside the curve on
\neverReached\ datasets and started above it on \startedAbove.

\subsection*{H4 --- Reading the features better: \hFourSupported}

\emph{A better reader gets more class information out of the same images.} Two steps, each
changing exactly one thing, on the \hFourSubsample\ images every reader was scored on:
\hFourBaseline\ at no reasoning effort, the same model asked to think at \texttt{medium}
(\textbf{H4a}), and \hFourFrontier, a frontier model asked to think as hard (\textbf{H4b}).
The second step cannot be run against the no-reasoning baseline, because the frontier model cannot
be asked to stop reasoning; holding the effort fixed instead is what makes it a comparison of
models rather than of models and effort together.

The measure is a cross-validated probe on the concept answers, not arm B and not arm C. Arm B
reads the answers through the nearest-fingerprint rule, which H2 showed to be lossy, so a
comparison of readers through it would be a comparison through a broken channel; arm C would need
a labelled pool for every reader, which this study deliberately does not buy. The probe fits arm
C's classifier inside the scored images themselves by stratified cross-validation, with folds
fixed by seed and identical across readers, and every image is scored by a fit that never saw it.
It measures what the answers carry. It is not a point on the learning curve, and no $n_B$ reads it.

Two limits on H4b. The frontier model is closed and of unknown size, so the step is capability and
not parameters. And it refuses \texttt{temperature: 0} --- only its served default is allowed ---
so it is the one reader here whose answers are sampled rather than deterministic; they would differ
if re-bought, and the paired bootstrap cannot see that, because it resamples images over answers
that are fixed only in the archive.

H4a won on \hFourAWins\ of \numDatasets\ datasets and H4b on \hFourBWins\ of \numDatasets;
both are held to the 6-of-6 rule H1 and H2 are held to, since 5 of 6 is $p = 0.11$ and six
datasets cannot do better. All \numReaders\ readers are reported in
Table~\ref{tab:h4} and Figure~\ref{fig:readers}, not only the three the chain reads.

\section{Extension: reading the arms against the published literature}
\label{sec:literature}

Everything in this section is a fixed comparison point, not a computation, and it decides no
hypothesis. \texttt{data/literature/benchmarks.yaml} pins the AUC and ACC that
\cite{yang2023} report for five fully supervised methods on these same six MedMNIST v2 tasks at
the same 224-pixel resolution --- trained on each dataset's whole official training split,
thousands to tens of thousands of images, not this study's $n \leq 2000$ labelled pool. Table~%
\ref{tab:literature} sets every arm of this study beside the best of those five published numbers,
so a reader can see how far a handful of labels and a textbook prior sit from a benchmark trained
at full scale, without mistaking the gap for a finding about any arm here.

Read that way, the gap tracks the label budget and little else. The best zero-label arm on each
dataset --- whichever of A and B wins there --- sits a median \litGapZeroMedian\ AUC below the
published best, and is within five points of it on \litZeroWithinFivePoints\ of \numDatasets\
datasets. Buying \litLargestN\ labels closes most of what remains: the pixel probe's median gap is
\litGapPixelMedian, within two points of the ceiling on \litPixelWithinTwoPoints\ of \numDatasets\
and at or above it on \litPixelAtOrAboveCeiling, while the concept probe at the same budget sits
\litGapConceptMedian\ below it. The ordering is the
same one H1 reports --- pixels with labels beat the textbook without them --- now with an external
scale attached to it.

Two cautions on reading the table. The published methods see each dataset's whole official training
split, so none of this is a same-conditions comparison, and the gaps above are not differences any
bootstrap here covers: they subtract a number from another paper, with no interval. And the last
column is the best of five methods per dataset, which is not always the same method; the figure
instead draws the ResNet-18 (224) row alone, the one backbone trained at this study's own input
resolution, as a finely dotted line on Figure~\ref{fig:curve}. Table~3 of \cite{yang2023} reports
ACC beside AUC and \texttt{benchmarks.yaml} pins both, but only AUC appears here: this study
computes no ACC for any arm, and a published ACC with nothing to set beside it would be decoration.

\section{What this study cannot separate}

Every source dataset is public and labelled, so ``the model carries textbook knowledge'' and ``the
model has seen this benchmark'' are not distinguishable with these data. Not claimed: that the
concept scores are clinically valid, that the simulated review substitutes for a clinician, or that
any arm is state of the art.
